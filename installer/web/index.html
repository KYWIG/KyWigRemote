Installer le client de connexion distante

Console de gestion des connexions RDP et SSH. L'installation est prise en charge par Windows (ClickOnce) : le client se met en place pour votre session, avec un raccourci dans le menu Démarrer. Aucun composant supplémentaire n'est requis.

Installer KyWigRemote
Éditeur : KyWig Informatique · Runtime .NET embarqué (rien à installer).
Si l'installation ne démarre pas automatiquement, téléchargez puis ouvrez KyWigRemote.Client.application.
La désinstallation se fait depuis Paramètres › Applications.
